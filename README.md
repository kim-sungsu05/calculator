# Calculator GUI

Java Swing으로 계산기 GUI를 구현하며 **Java 객체지향 프로그래밍(OOP)과 이벤트 처리**를 학습하기 위한 프로젝트입니다.

## Tech Stack

- Java
- Java Swing / AWT
- JDK

## 주요 기능

- 계산기 GUI 구성
- 숫자 및 연산자 버튼 생성
- 버튼 클릭 이벤트 처리
- 사칙연산 및 입력값 초기화

## 학습 내용

- **OOP:** 클래스, 객체, 상속, 다형성
- **GUI:** Swing 컴포넌트와 배치 관리자
- **이벤트 처리:** 버튼 클릭 이벤트
- **코드 구조화:** 배열과 반복문을 활용한 컴포넌트 생성

## 사용 방법

1. 프로젝트를 클론하고 VS Code에서 엽니다.
2. `main()` 메서드가 있는 클래스를 실행합니다.
